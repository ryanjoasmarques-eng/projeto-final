# 🚗 Concessionária de Veículos

Projeto desenvolvido em **HTML5 e CSS3**, com a temática de uma concessionária de automóveis. O objetivo é apresentar diferentes categorias de veículos por meio de um site organizado, intuitivo e visualmente agradável.

## 📌 Sobre o projeto

O site foi desenvolvido como atividade acadêmica, com o propósito de praticar conceitos de desenvolvimento web, estruturação de páginas HTML e estilização com CSS.

## 📄 Páginas do projeto

- **Início:** página principal da concessionária.
- **Estoque:** apresentação dos veículos disponíveis.
- **Sedans:** seção dedicada aos carros sedans.
- **SUVs:** apresentação dos veículos utilitários esportivos.
- **Esportivos:** seção de carros esportivos.
